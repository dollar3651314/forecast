## 1. 结论
- 新模块 `market`：市场（三语题目、规则、选项和判定条件）、状态机（**只允许 17 条边**，其余 83 种组合全部 409 `ILLEGAL_TRANSITION`）、上架检查清单（必填项一次列出全部缺的、勾选"已检查以上各项"）、补充说明、提前截止、费率修改（`fee:edit`、高危、原因必填、审计前 → 后、修改记录公开、上架后改的发 #22）、截止任务和事件结束任务（数据库租约，多实例只执行一次）、下注前的截止屏障（`MarketApi.lockForBet`，给 S4 用）。
- 每次状态跳转都是**带旧状态的条件更新**，同一事务写状态历史：重复触发、多实例同时触发都只生效一次（8 线程并发测试、两个实例同时跑截止任务测试）。
- 可调时钟：后端测试沿用 `MutableClock`；端到端测试新加 e2e profile 下的 `/api/e2e/clock/*`（系统时间 + 偏移量）和 `/api/e2e/markets/tick`。
- 后台接口：市场的列表、详情、新建 / 编辑 / 删除草稿、提交上架、退回、上架、暂停、恢复、提前截止、取消、补充说明、改费率；参数设置的查看和修改（品类默认费率 `fee:edit`；其余 `betting_params:edit`）。客户端接口：市场列表、详情（最小契约测试）。**页面都没有做**（等原型确认）。
- 权限点：按需求第 2.2 节一次加齐 21 个（32 → 53），后台前端的权限点清单和翻译同步；**单笔最小提现从 `config:edit` 改为 `betting_params:edit`**（S2 遗留），从系统配置页搬到参数设置。
- S3 没有下注和退款：截止时"有效选项不足 2 个 → 作废退款"只做状态跳转（CLOSED → VOIDED，原因代码 `NOT_ENOUGH_OPTIONS`），奖池信息和退款通过两个接口留给 S4、S5 实现（`MarketPoolView`、`MarketListener`，第 2.4 节）。**所以在 S4 之前，所有市场到点都会按 E4（总奖池为 0）作废**——这是规则本来的结果（没有下注），不是缺陷。
- 迁移：`V9__market.sql`（5 张 market 表 + `common_job_lease`）、`V10__market_params.sql`（参数初始值 + 模板 `FEE_CHANGED`）。V1～V8 没有改。
- 本地实际执行：后端 356 个测试（新加 43 个），0 失败、2 个跳过（同 S1、S2）；后台前端 lint、162 个单元测试、构建、品牌和模拟层检查通过；客户端、官网没有改代码，只为端到端重新构建；端到端两种形态全部通过（含新加的市场用例）；索引检查、仓库品牌检查、gitleaks 通过。详见第 5 节。

### 2.3 规则怎么落到代码
| 需求 | 实现 |
|---|---|
| 状态只按图走（AC-10） | `MarketStateMachine.check`；Mapper 的跳转带 `WHERE status = 旧状态`；`MarketTransitionDbTest` 在库里穷举 100 种组合 |
| 必填项（AC-11、第 4.1 节） | 保存草稿时：品类、选项 2～10 个、四个时间都有且先后正确、单客户上限只能调低（不超过品类默认值）。提交上架和上架时：三语题目、三语规则、每个选项的三语文字和三语判定条件、裁决方式、首选和备用来源、平台裁决的争议窗口。都是一次列出全部（C56）；详情接口返回 `missing`，后台页面直接用它显示检查清单 |
| 上架（第 4.1 节、RQ-17） | 勾选 `checked`、必填项齐全、截止时间还没过；有 `market:publish` 的人可以上架自己建的草稿；提交上架只加标记（不是状态） |
| 上架后不能改（AC-12） | 修改语句只对草稿生效，上架后 409 `MARKET_NOT_EDITABLE`；只能发补充说明（截止前，三语，按时间显示）、提前截止（只能提前、晚于开放时间）、改费率 |
| 暂停（AC-14） | 暂停 / 恢复要原因（高危）；暂停中 `lockForBet` 拒绝（`MARKET_PAUSED`）；暂停中到了截止时间由截止任务进入"截止下注"（第 5 条边）；截止时间已过的不能恢复 |
| 截止判定（AC-15） | `openAt ≤ receivedAt < closeAt`；T − 1 毫秒通过、T 拒绝；截止任务拿排他锁，下注拿共享锁 |
| E3、E4 | 截止事务里问 `MarketPoolView` 有效选项个数，&lt; 2 同一事务 CLOSED → VOIDED（原因代码 `NOT_ENOUGH_OPTIONS`）并通知 `MarketListener` |
| 费率（第 3.8 节、AC-37 前半） | 新建按品类默认值带出（改品类默认值只影响之后新建的）；0～20%、最多 2 位小数；草稿到争议中都能改，终点状态或 `settle_phase ≠ NONE`（S5 开始结算后）409 `FEE_LOCKED`；每次修改写 `market_fee_change`（客户端公开时间和旧 → 新）；上架后改的发 #22 给有下注的客户（S3 名单为空，测试用替身验证） |
| 时区（第 3.7 节） | 库里 UTC、精确到毫秒（写入前截到毫秒，避免 MySQL 四舍五入让时间往后跳）；接口是 ISO-8601 UTC；通知里写"yyyy-MM-dd HH:mm UTC" |
| 停机恢复（NF-05） | 任务按"条件已满足"扫描，停机期间到期的恢复后第一轮处理（测试覆盖） |
